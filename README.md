# lampa-store-clean-v4-installed-status

Исправления:
- В магазине теперь показывается статус карточки: "Установлен" / "Не установлен".
- Статус определяется мягким поиском ссылки плагина в localStorage/sessionStorage/Lampa.Storage.
- Кнопка "Закрыть" пытается вернуть в настройки, а не в экран ввода URL плагина.
- У кнопки перезагрузки увеличены отступы слева и справа: margin 0 .42em.
- Размер самой кнопки слегка увеличен до 2.42em.
- Дизайн магазина сохранён.

Важно:
Родное подтверждение установки Lampa всё равно открывается родным экраном Lampa.
После установки вернись в Дом плагинов и нажми "Обновить" — статус должен стать "Установлен".
