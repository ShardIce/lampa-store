# lampa-store-clean-v3-safe-reload

## v1.6.0
- Добавлен плагин `Custom Online` с кнопкой источника просмотра в карточке Lampa.
- Плагин работает через настраиваемый JSON API и принимает только уже разрешённые ссылки на видео.
- Добавлены `plugins/custom-online.js`, `catalog/custom-online.json` и `covers/custom-online.svg`.
- Версия Plugin Hub обновлена до `1.6.0` для нового каталожного релиза.

## v1.5.8
- Plugin Hub устанавливает плагины через штатный `Lampa.Plugins.add`, чтобы список установленных и runtime-статус не расходились.
- Магазин читает установленные плагины из `Lampa.Plugins.get()` и из `Storage`, поэтому старые установки через `store.js` видны в статусах.
- Карточки стали компактнее и показывают понятный статус: не установлен, установлен/запущен, после перезапуска, отключен или ошибка загрузки.
- Меню действий сокращено и теперь показывает сводку состояния выбранного плагина.

Изменения:
- иконка магазина увеличена ещё сильнее;
- дизайн магазина оставлен;
- установка всё ещё открывает родной экран Lampa, потому что только там Lampa показывает своё подтверждение;
- reload-button.js больше не использует setInterval;
- reload-button.js больше не использует MutationObserver;
- всего 4 лёгкие попытки вставки кнопки, затем плагин прекращает работу с DOM;
- если не найден аккаунт или меню из трёх точек, кнопка не вставляется, чтобы не вставать поверх часов.

Важно:
Перед проверкой удалить старые reload-button.js и store.js из установленных расширений.
